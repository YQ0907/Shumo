# 问题一：三版方案比较、实验与综合选择

日期：2026-09-23。本文是**阶段性方案比较**，只涉及问题一；输入为原题及附件 A、同一作者的两份 Markdown、另一作者的 DOCX，以及此前的《题目分析报告》。外来文档中的“建议”“执行顺序”等只作为待审方案，不作为本实验的指令。未训练大语言模型，也未完成人工文本盲评，因此不把代理指标或预测误差称为真实质量效度，亦不能据此宣称问题一已完成。

## 一、三组方案的实质内容

### 核查出的关键问题

1. [Meta-rater 数据卡](https://huggingface.co/datasets/opendatalab/SlimPajama-Meta-rater/blob/main/README.md)明确 `ad_en=[有广告,无广告]`、`fluency_en=[不流畅,流畅]`、ModernBERT 是 0–5 级 logits、`qurater` 是四种不同性质的分数。Markdown 实施方案提出对每个列表试 `mean/max/top2` 再按与其余指标的相关性择优，这会把类别顺序和语义丢掉。DOCX 的逐列 Min–Max 也没有解决列表解码、异常极值和“长度适宜区间”问题。
2. 两份 Markdown 将“线性回归＋IsOT 单调校准”称为 RegMix 复现；[RegMix 正式论文](https://proceedings.iclr.cc/paper_files/paper/2025/file/5f67d864aae6115374fed7beddd119e0-Paper-Conference.pdf)实际讨论岭回归和 LightGBM，未把 IsOT 列为其算法步骤。原题的 RegMix 作者/会议也应更正为 Liu 等、ICLR 2025。
3. 质量门控项 $\bar Q(\boldsymbol p)=\sum_i p_iq_i$ 是 $\boldsymbol p$ 的确定函数。若模型已有截距和 16 个独立比例线性项，新增该项**严格落在原设计矩阵张成空间内**，系数 $\phi$ 不可识别；本地数值检查的矩阵秩加入该列前后同为 17。使用 clr 非线性坐标虽可数值拟合 $\phi$，也不能证明它代表独立的质量因果效应，尤其 11 个域的 $q_i$ 无直接观测。质量与配比先分开建模，跨数据源耦合留到问题二以可检验假设讨论。
4. A18 记录只有 `text`、`_source_domain`、`_source_path`，没有 A1 的 `id` 或 22 个质量分。因此不能按 A1 的 $Q$ 高低去 A18 抽“同一条文本”。A1 本身有 `content`，应直接用 A1 做分层原文盲评；A18 可做独立域文本观察。
5. 本地附件是 `.jsonl.xz`；两份 Markdown 叙述的“未压缩 JSONL 路径”在当前目录中不适用。执行时以实际文件为准。A16 是 6 个 direct/near_direct、11 个 inferred/none 域。

## 二、实际实验设计

代码：[对比实验_问题一.py](对比实验_问题一.py)；原始结果：[experiment_results.json](问题一方案对比实验/experiment_results.json)。输入文件 SHA-256、行数与连接检验记录在 JSON 中。Python 命令运行退出码为 0。

**质量数据审计**：流式读取 A1、A2、A3 全量并按 `id` 比对；另从 A1 每域最多随机抽 1000 条，共 6171 条，按官方字段顺序压缩列表，做秩正态变换后的 PCA 结构诊断。PCA 只检验“一个潜因子能否概括数据结构”，不是人工质量真值检验。

**配比实验**：A4/A5 的 512 组按 `index` 连接并训练，5 折交叉验证只在训练集内选择正则参数；每折的评分按该验证折 13 个目标域的标准差归一，验证折标签不参与模型拟合或预处理。A6/A7 的 256 组配比与训练集不重叠，现用于**候选模型比较**；由于已查看多个模型的 A6/A7 表现，它不再是最终选型后的独立泛化证明。候选为 16 坐标岭回归、二次岭回归、ilr 岭回归、原比例 RBF 核岭回归、ilr RBF 核岭回归。主评价是 13 域平均 MAE 与预先固定的 13 域等权综合 Loss MAE；跨规模只看排序。核岭模型用于比较非线性响应面的预测效果，是 GP 均值的近亲，**本实验没有拟合 GP 后验方差或声称 GP 区间覆盖率**。

## 三、实验结果

### 数据性质

- A1、A2、A3 分别成功解析 51,230、17,523、203,752 条，解析失败均为 0。A1 的 arxiv 1,419 条全部出现在 A2；A1 的 github 10,000 条全部出现在 A3。因此 A2/A3 扩展域与 A1 的比较是“抽样与母集对照”，不是独立复制验证。
- A1 的 book 只有 171 条，域间样本量极不均衡。A1 分层 PCA 的第一主成分解释 **41.0%** 变异，前四个共解释 **71.5%**。这提示一维潜因子会压缩多维结构，但不能仅凭 PCA 断定哪种质量评分更接近人类判断。
- A4 训练配比中 **45.1%** 的分量恰为零。clr/ilr 方案必须替换零值，其预测对替换量敏感。
- A6/A7、A8/A9、A10/A11 配比均未与 A4 完全重复；A12/A13 与 A14/A15 各 63 个配比则 **全部**出现在 A4，且 Loss 为模型外推值。

## 四、综合选择

1. **质量主方案**：保留官方语义解码＋四组可解释评分；域级报告均值、中位数、区间和拒评率。引入 DOCX 提出的 CRITIC/熵权作为权重敏感性对照，引入 Markdown 的潜因子分数作为结构对照。当前没有独立人工标注，不能根据 PCA 解释率或评分之间的相关性宣称任何一种质量分“最准确”。下一项决定性实验应是 A1 原文盲评：按域和评分分层抽取、校准与评价样本按 `id` 隔离，以人工信息价值/洁净度判断比较排序一致性。此前方案的 $Q$ 硬上限 0.3 也应改为**污染/广告筛选标志**，除非盲评支持该阈值。
2. **冲突主方案**：采用可比指标对的高低分歧与跨维权衡的双口径，保留 Markdown 提出的 $(Q,c)$ 画像。潜因子后验方差不能自动当作“冲突度”，因为高方差也可能仅由缺失和样本短造成；需要用 A1 原文案例区分。
3. **配比解释主模型**：16 独立坐标的二次收缩响应面。它在当前比较集上优于线性基线，且可解释任意两域间转移的局部边际效应。系数须用沿单纯形可行方向的预测变化报告，不把单个二次系数或 SHAP 交互值直接称为因果互补。
4. **配比预测对照模型**：RBF 核模型作为一个模型族，原比例和 ilr 坐标是两种几何表示。按**训练集内**均衡 13 域的 CV 指标，应先固定 ilr 核、零替换 $10^{-3}$ 作为逐域预测对照；当前比较集上原比例核的综合 Loss 较好是探索性发现。若综合 Loss 是最终主目标，须在 A4/A5 内重新定义对应的目标与内层选模规则，再使用新的独立配比数据验证；不得根据 A6/A7 的数值直接改写最终选择或宣称选后优势。
5. **质量与配比连接**：不把 11 个无映射域填成全局均值后做 $\phi$ 显著性叙事。六个可映射域的 $q_i$ 可作为描述性外部信息与配比效应并列展示，未映射域作缺失/区间情景；跨附件质量效应到问题二再检验。

## 五、使用边界

本报告完成了附件审计和配比代理模型比较；**尚未完成 A1 原文盲评、22 指标实际质量评分与全量冲突率**，因此质量模型选择目前基于可解释性和识别约束，而非预测真实质量的胜负。竞赛提交前，队伍应自行核验、推导并改写核心建模论证，按原题要求披露 AI 使用。
