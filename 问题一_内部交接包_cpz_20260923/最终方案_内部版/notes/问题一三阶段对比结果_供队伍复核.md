# F 题问题一：三阶段模型对比结果（供队伍复核）

**跨任务更新**：已读取并对齐另一任务 F_Q1-2 的质量与 ilr 核模型实验。综合结论以[跨任务比较](F_Q1-1与F_Q1-2综合比较.md)为准；下文配比表只覆盖本任务最初的五条模型路径。

本页汇总已经运行的 A1–A15 探索实验。它是队伍复核和自行完成核心推导的工作底稿，不能直接充当竞赛论文中的独立人工验证。原题规定 AI 不能代替队伍完成核心建模与论证，并要求披露 AI 使用。所有数值来自本地附件和对应代码；外部论文的方法与边界见[论文研读与路径比较](../问题一_论文研读与模型路径比较.md)。

## 1. 质量评价：保留可解释基线，等待非 AI 核验

A1 的 51,230 条、A2 的 17,523 条、A3 的 203,752 条均完成 22 指标预处理和评分；A1 与 A2/A3 有重复，不能把三者简单相加当独立样本量。多维指标按字段语义压缩，非有限 ModernBERT 字段作为缺失，不删整条记录。按教育价值、可读性、洁净度、结构四组等权是**可解释基线**。另外比较了 22 指标平权、四组中位数及 PCA 结构分；PCA 无语义监督，不可因解释方差高而称为质量真值。完整七域均分及扩展域对照见[质量阶段结果](质量阶段结果.md)。

两名 AI 子代理只看 135 条原文**前 1500 字**，各评分 68/67 条；另有 40 条交叉复评。信息价值、可读性、噪声三项的复评精确一致率分别为 87.5%、80%、80%，二次加权 κ 为 0.917、0.780、0.899。这只是 AI 评分者间一致性，不是人类真值或预训练收益。盲评与模型的相关如下；抽样按域与模型分层，不能按总体相关推断全量样本准确率。

| 质量路线 | 与 AI 片段综合分的总体 Spearman | 七域内 Spearman 中位数 | 解释 |
|---|---:|---:|---|
| 四组等权 | 0.531 | **0.621** | 域内一致性略高、规则易解释 |
| 22 指标平权 | **0.585** | 0.602 | 总体相关略高，易重复计入高度相关指标 |
| 四组中位数 | 0.393 | 0.519 | 抑制极值，但可能压掉有意义的专业信号 |
| PCA 结构分 | 0.259 | 0.349 | 风格/域结构诊断，不作为质量结论 |

book 域四组等权的域内相关约 −0.01，仅 20 条且部分截取到版权页/目录，不能据此评价整本书。AI 评分不构成 A3 监督权重学习所需的人类标签。现阶段推荐在后续计算中携带四组等权与平权两个评分作敏感性分析，不宣布语义最优权重。供阅读的[AI 子代理已填盲评表](quality_results/原文盲评样本_子代理AI评分.csv)没有模型分数，原始空白盲评表仍保留。核验文件：[AI 盲评摘要](quality_results/AI盲评核验摘要.json)、[AI 盲评与模型对照](quality_results/AI盲评与模型对照_内部.csv)、[完整模型评分](quality_results/sample_scores.csv)。

## 2. 冲突识别与消解：标记并留痕，暂不自动改分

初始实验在四对指标中查高低冲突：方向化分数 ≥0.8 对 ≤0.2，且两项原值落在 A1 同域第 1–99 百分位内。A1/A2/A3 分别检出 1,037/0/4,396 条；按总体条数约 2.02%/0%/2.16%。其中前三对是语义可比信号，二/三元组一对更适合作为**结构分歧**单列。跨任务对账发现它对并列值的分位数算法高度敏感，正式冲突主表建议只报前三对，见[跨任务比较](F_Q1-1与F_Q1-2综合比较.md)。A2 的 0 是这套门槛下的检测结果，不能解释为 arxiv 原文绝无质量冲突。四对的合计冲突次数会重复计数，同一文本可能有多对冲突。

| 消解路线 | 实际操作 | 对 135 条 AI 盲评的诊断 |
|---|---|---|
| B1 原分加冲突标记 | 四组等权分保持，单列 `conflict`，需对重要案例读原文 | 全体 ρ=0.531；32 条冲突样本 ρ=0.151 |
| B2 稳健聚合 | 用四组中位数替代四组均值 | 全体 ρ=0.393；冲突样本 ρ=−0.103 |
| B3 组内共识校正 | 用同组其余指标中位数替换明显偏离的一侧；不明确时保留 | 全体 ρ=0.492；冲突样本 ρ=0.066 |
| B4 暂缓评分 | 冲突样本转交复核，其余保留 B1 原分 | 剩余 103 条 ρ=0.629；B1 在同 103 条上也是 0.629，不能称改进 |

B3 在 A1/A3 冲突样本上的平均绝对改变量约 0.041/0.040，且和 AI 片段评分的相关**下降**；因此没有证据把自动修正设为默认。建议采用 B1：保留原分、附冲突类别与证据，优先复核对结论有影响的样本。B4 可用于审核队列，不能仅因剔除难例后相关变高就宣称评分更准。成因至少区分模型任务定义差异、领域/文体差异、统计特征与语义质量不一致、解析/截断问题；当前冲突率本身不能确定成因。证据文件：[策略汇总](conflict_results/policy_summary.json)、[逐条策略分数](conflict_results/route_scores.csv)。

## 3. 核心模型：17 域配比预测 13 域 Loss

令配比 $p_i\ge0,\ \sum_{i=1}^{17}p_i=1$，只使用前 16 个配比坐标，最后一维由和约束确定。A4/A5 的 512 对训练配方和 Loss 通过唯一 `index` 一对一连接；原始行和最大舍入偏差 0.004，逐行归一。13 个验证域各输出一个 Loss；等权平均 Loss 仅是清楚声明的示范目标，不能代表所有任务权重。比较五条可运行路径：线性 ridge、二次 ridge、RBF 核回归、Extra Trees，以及 $L_r(p)=c_r+\exp(a_r+b_r^\top p_{1:16})$ 的正超额 Loss 路线。最后一种是受 Data Mixing Laws 启发的简化指数代理，**不是**论文完整法则的复现；$c_r$ 只从对应训练折估计。Extra Trees 是 RegMix 式非线性树预测器的本地替代，并非 LightGBM 复现。

各模型超参数只在 A4/A5 的五折交叉验证中选择，预定主要指标是 13 域按训练折标准差归一后的 MSE。1M 检验的绝对误差、60M/1B 的排序及 10B/70B 的估算排序均为**事后探索**：工作区较早的另一份实验已查看过检验集，不再声称盲测独立性。

| 路线 | 训练 CV 13 域标准化 MSE ↓ | 训练 CV 综合 MAE ↓ | 1M 检验综合 MAE ↓ | 综合 Loss Spearman：1M / 60M / 1B ↑ | 前 10% 优良配方找回：1M / 60M / 1B ↑ |
|---|---:|---:|---:|---|---|
| 线性 ridge | 0.402 | 0.224 | 0.181 | 0.625 / 0.559 / 0.367 | 0.31 / 0.27 / 0.43 |
| 二次 ridge | 0.372 | 0.186 | 0.149 | 0.707 / 0.687 / 0.598 | 0.31 / 0.27 / 0.57 |
| RBF 核回归 | 0.333 | 0.172 | 0.140 | 0.756 / 0.736 / 0.532 | 0.38 / 0.35 / 0.29 |
| Extra Trees | 0.407 | **0.125** | **0.105** | **0.914 / 0.843 / 0.686** | **0.81 / 0.77 / 0.57** |
| 正超额 Loss 指数代理 | **0.317** | 0.196 | 0.148 | 0.748 / 0.699 / 0.427 | 0.31 / 0.27 / 0.57 |

在本表原有五条路径中，按预定的逐域 CV 指标，指数代理最优；纳入 F_Q1-2 的 ilr RBF 后，它的同口径 CV 更低（0.153 对 0.317），应将 ilr RBF 作为**逐域预测主候选**，而把指数代理保留为平滑解释和问题二连接的对照。若队伍事先将目标定义为**等权综合 Loss 的配方筛选**，训练 CV 综合 MAE 支持 Extra Trees，但必须同时说明其逐域标准化 MSE 更高、局部变化不平滑。不能看过 A6/A7 后才改目标并称预注册。1M 检验集中，Extra Trees 比指数代理的综合 MAE 低 0.043，按 256 对配方的事后配对 bootstrap，差值 95% 区间约 [−0.058, −0.029]；这仍不恢复独立测试地位。

与 RegMix 原文的目标保持一致时，应单看 Pile-CC 验证 Loss，而不是把 13 域等权平均误认为原论文目标。指数代理在 Pile-CC 的 1M/60M/1B Spearman 分别为 0.934/0.927/0.938；Extra Trees 为 0.802/0.790/0.437。因而“配比排序跨规模稳定”在本附件中**随目标和模型而变**：对 Pile-CC 的指数代理有较强支持，对 13 域等权综合目标不能直接借用该结论。原论文研究用 Pile-CC 目标的依据及其与下游任务的经验关联见[RegMix 正文](https://arxiv.org/abs/2407.01492)第 3–4 节；本题未提供可把其权重原样移植到全部任务的证据。

### 局部替代与组合

从 Pile-CC 转移 1 个百分点到另一训练域，在训练配比附近计算预测平均 Loss 差。情景仅保留非负、总和为 1、目标域不超过训练第 95 百分位且最近邻距离在训练近邻的第 95 百分位内的配方。本次小扰动的最近邻门槛实际没有剔除行，主要筛选来自目标域占比上限；这不能证明多域联合位置都在充分观测的范围。16 个方向完整结果在[单域转移表](mixture_results/one_point_transfers.csv)。ArXiv、PubMed Central、StackExchange、DM Mathematics、Ubuntu IRC 的三条非线性/二次路线均预测平均 Loss 下降，但幅度差异明显。NIH Exporter、PhilPapers、Enron Emails 等低占比域的树模型方向与指数/二次模型相反，故不能给出稳健“应该增配”的结论。所有这些都是拟合函数上的局部情景，**不是随机实验得到的因果效应**。

同样从 Pile-CC 各转出 1 个百分点给两域，按差分 $f(p+\delta e_i+\delta e_j-2\delta e_{cc})-f(p+\delta e_i-\delta e_{cc})-f(p+\delta e_j-\delta e_{cc})+f(p)$ 估计组合项。120 对中只有 43 对在指数、二次与树模型三路符号一致；目前不能稳健宣称具体领域互补或替代。详见[两域组合表](mixture_results/two_domain_interactions.csv)。

### 外推边界

A8/A9 的 60M、A10/A11 的 1B 是不同参数规模的检验表，表中仅比较**配方排序**，不能把 1M 模型输出直接当作它们的绝对 Loss。A12–A15 的 10B/70B Loss 是估算值，63/63 个配方与 A4 训练配方重合，均非独立大模型实测。五条模型在两张估算表的综合 Loss Spearman 全为负；例如 Extra Trees 为 −0.739/−0.814，前 10% 找回均为 0。这直接限制了跨大规模综合配方推荐，不宜把 1M 排序稳定的假设无条件带入问题二。完整数值与协议见[模型比较 JSON](mixture_results/model_comparison.json)。

## 4. 质量分与配比模型的接口

A1–A3 的七个质量域与 A4–A15 的十七个配比域不同。A16 仅有 3 个 direct、3 个 near_direct，其余 11 个 inferred 映射。当前数据没有对“改变 A1–A3 质量分并保持配比不变”后的 Loss 实验，因此本阶段**不把质量 Q 强行作为第 18 个配比回归自变量**，也不把七域分数伪造成十七域观测。可给问题二提供四组等权与平权质量分的敏感性情景、A16 映射等级，以及配比到 Loss 的 13 维函数；队伍需另外提出可检验的跨数据源连接假设。

## 5. 复核状态与待决事项

代码及本地完整输出：[质量](quality_results/)、[冲突](conflict_results/)、[配比](mixture_results/)。`mixture_compare.py`、`conflict_compare.py`、`assess_ai_blind.py`、`mixture_effects.py` 均通过独立 P1 复核；配比脚本另行隔离重跑，六对表的行数与连接关系一致，局部效应已抽样复算。数学建模只读复核要求保留上述目标定义、估算表与 AI 盲评的证据边界。局部效应是模型情景诊断，即使复算一致也不宜单独作为论文因果结论。
