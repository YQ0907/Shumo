本页来自 `python 问题一研究/quality_compare.py --output 问题一研究/quality_results` 的实际运行，退出码 0。代码仅读取附件，输出位于 `quality_results/`。分数是按预定规则构造的**信号综合指标**，尚未经独立原文盲评验证，不能解释为预训练收益或客观质量真值。

## 2. 候选评分路径对照

代码实际计算四个可运行版本：四组等权、22 指标平权、四组中位数、PCA 首主成分结构分。前三者依赖同一方向转换；PCA 仅作结构诊断。A1 样本中，四组等权分与 22 指标平权分的相关为 0.954，与四组中位数为 0.926，与 PCA 结构分仅为 0.480。PCA 强烈区分语料风格，不能凭方差解释率把它认作质量真值。

| A1 领域 | 样本数 | 四组等权均分 | 22 指标平权 | 四组中位数 | PCA 结构分 |
|---|---:|---:|---:|---:|---:|
| arxiv | 1,419 | 0.7575 | 0.7548 | 0.7754 | 0.9788 |
| book | 171 | 0.6468 | 0.6511 | 0.6634 | 0.8788 |
| c4 | 10,000 | 0.6561 | 0.6793 | 0.6388 | 0.4066 |
| commoncrawl | 9,640 | 0.6527 | 0.6674 | 0.6416 | 0.6566 |
| github | 10,000 | 0.5765 | 0.6306 | 0.5187 | 0.4005 |
| stackexchange | 10,000 | 0.6532 | 0.6953 | 0.6109 | 0.5809 |
| wikipedia | 10,000 | 0.6316 | 0.6622 | 0.6013 | 0.3868 |

四组等权是当前**可解释基线**，不是经独立验证选出的优胜模型。各域排名随聚合路径变化，尤其 github 与 StackExchange；不能只呈现一张域质量排名。图表和结论应同时给出多路径敏感性。

## 4. 冲突初筛与原文例子

按模型合同的四对语义可比指标、0.8/0.2 的方向分门槛及 A1 同域原值 1–99 百分位可靠性门槛，A1 的冲突记录共 1,037 条。A2 arxiv 全量为 0 条，A3 github 全量为 4,396 条；A3 含 A1 github 的 203 条冲突记录。A1 各域冲突率：book 9.94%、c4 2.59%、commoncrawl 1.86%、github 2.03%、stackexchange 1.52%、wikipedia 2.27%、arxiv 0%。book 仅 171 条，冲突率尤其需要区间和原文核验。

原文抽检中，c4 低分例 `BkiUbbPxK6nrxqmoxxiD` 是重复堆砌的商品关键词，高分例 `BkiUdTc5qsMAIxrFvAlC` 是完整的技术说明；这与质量分方向一致。github 低分例 `BkiUfpo25V5jWXnENLXA` 是 CSS 片段，高分例 `BkiUafnxK0iCl4WD151B` 是项目文档；这里反映了**代码与说明文档的偏好**，不能直接推断代码语料训练价值低。此前将广告/洁净度相对低百分位自动当作污染并封顶的规则，会误伤正常 arxiv 原文，已撤销。

独立评价所需的 135 条[原文盲评样本](./quality_results/原文盲评样本.csv)已生成；抽样层级和模型分数保存在内部索引，不应交给评阅者。评阅后需把人工 0–3 分与四条评分路径做相关、错判和域别检查，再确定最终质量评分路线。现阶段不能声称完成这一验证。
