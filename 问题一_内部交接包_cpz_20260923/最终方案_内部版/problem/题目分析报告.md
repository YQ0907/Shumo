# F 题问题一：建模方案草稿

> 范围：仅讨论问题一。此文是供队伍推敲的方案，不含实际拟合结果；题目规定核心建模、推导与论证须由参赛队伍自行完成并披露 AI 使用。

## 2. 数据核对与预处理

1. A1–A3 均是 JSONL.xz。A1 有 `content`、`_source_domain`，A2/A3 没有原文，来源域由文件名确定。实际文件中的 8 个列表型字段是 JSON 数值列表，`json.loads` 每行后可直接按数组处理，须检查列表长度和非有限元素；其元素意义按[数据集官方字段说明](https://huggingface.co/datasets/opendatalab/SlimPajama-Meta-rater/blob/main/README.md)处理，具体压缩见下表。

## 3. 质量评价

设文本为 $t$、指标为 $j$，方向处理与压缩后的原值为 $x_{tj}$。用 A1 的稳健经验分布将其变成 $u_{tj}\in[0,1]$；正向用经验分布函数 $F_j(x_{tj})$，负向用 $1-F_j(x_{tj})$，适宜区间型指标用离适宜区间的距离构造单峰函数。语义型正/负指标采用 A1 **总体**参照，使各域分数可比较；仅长度、标点、字形等结构适宜区间采用 A1 **同域**参照，避免将代码或公式的格式误判为低质量。上下 1% 分位处截尾可减少极端值影响，阈值须做敏感性分析。缺失项不填为零，而在对应指标组内按可观测权重重新归一化，并报告覆盖率。

将 22 指标按教育/推理价值、语言可读性、洁净与广告、文本结构四组整理。组内等权，组间等权作为主方案；这些权重不使用人工评价集调节。一个可检验的样本分数为

$$Q_t=\sum_{g=1}^{4}w_g\,\frac{\sum_{j\in g,\,j\text{可用}}v_j u_{tj}}{\sum_{j\in g,\,j\text{可用}}v_j},\qquad \sum_g w_g=1,\quad w_g,v_j\ge0.$$

不要让 22 个高度相关信号被当成 22 份独立证据。若任一组无可解析指标，或全局可用指标不足 11/22，则标记该文本“不评分”并报告各域拒评率；其余文本仅在组内对可用指标重新归一化，四个组的权重仍各为 $1/4$。此覆盖率门槛是预设的实施规则，需报告不同门槛下的稳健性。领域质量以该域所有可评分样本 $Q_t$ 的均值、中位数、10%/90% 分位和按文本/簇重抽样的区间报告；A2/A3 与 A1 同域分数使用相同变换。若 A1 为分层抽样，跨域总体均值需按真实域规模加权，不能简单平均 7 个域。

**原文核验**：在 A1 每域按评分高、中、低及冲突状态分层抽取文本，先按 `id` 固定分为不重叠的校准集和独立评价集。校准集仅用于检查方向和区间型假设及可选权重方案；主方案等权不调节。冻结后在独立评价集匿名人工按“信息价值、可读性、噪声”评分，计算秩相关、组间差异与误判案例。A2/A3 无 `content`，只能核验信号一致性和分布迁移；若需原文核验，按 `id` 寻找可对接原文或用 A18 的独立样例，但不得声称直接人工读过 A2/A3 原文。

## 4. 冲突定义与消解

仅在预先冻结的语义可比指标对内定义“高低冲突”。可比对为：`fineweb_edu` 与 `qurater` 的 Educational Value 分量；`fluency_en` 与 `modernbert_readability`；`modernbert_professionalism` 与 `qurater` 的 Required Expertise 分量；`rps_doc_frac_chars_top_2gram` 与 `rps_doc_frac_chars_top_3gram`。一个指标“可靠”在此仅指解析成功、原值有限且处于 A1 同域第 1–99 百分位内；超界值仍参加质量评分的截尾变换，但不参与冲突判定。若任一可比对的两个方向校正分满足 $u_{tj}\ge0.8,\ u_{tk}\le0.2$ 或顺序相反，则记该文本有语义冲突。`qurater` 两个参与冲突的分量在此单独标定，综合质量评分中仍按表压成一个标量。组间的“教育价值高但广告/洁净性低”另记为多维权衡：教育组分数不低于 0.8、洁净与广告组分数不高于 0.2；不称测量矛盾。上述 0.8/0.2 门限在 0.75/0.25、0.9/0.1 下做敏感性检查。

将冲突文本分为：（i）列表标量化或方向错误，（ii）领域特征导致的系统性差异，如代码/数学文本的可读性指标失真，（iii）短文本/异常文本测量噪声，（iv）真实的多目标权衡。对（i）修订转换后重算；对（ii）检查同域原文及结构适宜区间，不能事后为了提高域均值而重标定语义指标；对（iii）保留原分但标记低可靠，领域聚合时比较覆盖率加权与不加权结果；对（iv）保留四个组分数，不将相对低百分位自动解释为污染。基础综合分仍为上一节的 $Q_t$；稳健替代路线使用四组分数的中位数，并和基础分在独立原文评价集上比较。若队伍希望增加严重广告/污染的非补偿门槛，须先用校准集原文确认对应原始 logit/等级的语义阈值，冻结后才在独立评价集检验；相对百分位 0.1 不可直接充当此阈值。最小运行已证实旧规则将部分原始 `no-ad` logit 更高、洁净度也高的 arxiv 文本错误封顶，故旧规则撤销。

冲突处理前后分别报告 A1 各域冲突率、原文盲评一致率；A2/A3 用同一门限和规则报告扩展集冲突率及域质量分变化。两扩展集可能与 A1 重叠，统计区间按 `id` 去重或用配对比较。

## 5. 领域配比与 Loss

令 $\boldsymbol p_k$ 为第 $k$ 个 17 域配比，$L_{kr}$ 为第 $r$ 个目标验证域（13 个）的交叉熵。配比位于单纯形上；若直接放截距和全部 17 个线性项，会出现精确共线。选一个参考配比 $\boldsymbol p^{(0)}$，用前 16 个独立比例坐标 $z_{ki}=p_{ki}-p_i^{(0)}$，第 17 个由总和为 1 确定。可识别的基础响应面为

$$\widehat L_{kr}=a_r+\boldsymbol b_r^{\mathsf T}\boldsymbol z_k+\sum_{1\le i\le j\le16}h_{rij}z_{ki}z_{kj}.$$

对 $h_{rij}$ 用层级稀疏/岭收缩，且只在 A4/A5 内交叉验证选择惩罚及线性/二次模型形式。这样线性项解释相对第 17 域挪动小比例的效应，交互项描述组合效应。即使采用独立坐标，系数也依赖参考域选择；优先报告沿可行方向 $\boldsymbol e_i-\boldsymbol e_j$ 的预测变化与 bootstrap 区间。A6/A7 只评估已冻结的模型，不用于决定回退。

为汇总 13 个目标域，可预先固定目标权重 $\omega_r\ge0,\sum_r\omega_r=1$，定义 $L_k^{*}=\sum_r\omega_r L_{kr}$。首选等权；另报告按任务重要度改变权重后的结论和 Pareto 权衡，不用测试集挑选最有利权重。模型优化若要给建议配比，只在训练配比凸包内或其邻域求解 $\min_{\boldsymbol p\in\Delta^{16}}\widehat L^{*}(\boldsymbol p)$，并附训练分布距离约束，避免不可信的边界解。

**验证**：A6/A7 是同规模独立检验，报告 13 域及综合目标的 MAE、RMSE、Spearman 和相对于均值预测的增益。A8–A11 的模型规模不同，若未事先建立跨规模损失标定，不直接用 1M 绝对 Loss 与 60M/1B 绝对 Loss 算 RMSE；改比较配比排序、相对最差/基准配比的改善方向与域效应符号。A12–A15 是训练配比子集对应的外推 Loss，不是 10B/70B 实测；只用于检验排序/方向是否随外推尺度一致，不能当独立外部验证。任何检验集反馈若用于修模，必须公开标记为探索性，并另寻独立数据复验。

## 6. 质量与配比的连接

推荐主分析暂不把 $Q$ 当作配比回归的已观测协变量。A1–A3 的质量域与 17 个训练域不完全同源，A4–A15 没有逐配方实际质量标签；强行拼接会制造伪精度。先独立给出可直接映射域的质量分及不确定度：arxiv、github、stackexchange 为 direct；wikipedia_en、gutenberg_pg_19、pile_cc 为 near_direct。A16 中其余 11 域为 inferred/none，应列为缺失，若用 A18 原文特征估计，必须单列为情景推断而非观测。

若队伍确需为问题二构造 $Q(\boldsymbol p)$，可设 $Q(\boldsymbol p)=\sum_i p_iq_i$，并对缺失的 $q_i$ 给区间或多重插补，传播至后续结果。是否把此情景质量项纳入配比模型，须仅在 A4/A5 的交叉验证中裁决；A6/A7 只作冻结方案的检验。若无稳定的训练内增量预测，保留 $Q$ 与配比效应分开输入问题二。
