# F 题问题一：论文研读与模型路径比较（阶段 1）

**后续结果**：三阶段实测比较已整理到[问题一三阶段对比结果](问题一研究/问题一三阶段对比结果_供队伍复核.md)；原题六篇论文的逐篇适用性见[六篇论文与问题一的关系](问题一研究/原题六篇论文与问题一的关系.md)。本文件记录建模前的候选路径与预定比较口径，以下“尚未拟合”等描述仅指当时状态。

本阶段只确认文献方法、可用数据与候选路线；尚未拟合、选出最终模型或产生数值结论。后续按“质量评价 → 冲突消解 → 领域配比”推进，每阶段先用训练/校准数据比较，再冻结方案并在独立数据上检验。原题的 AI 使用要求仍适用，队伍应自行完成核心推导、核验与论证。

## 1. 已核对的论文与可借鉴内容

| 论文 | 实际方法与可借鉴点 | 对本题的适用边界 |
|---|---|---|
| [Meta-rater, ACL 2025](https://aclanthology.org/2025.acl-long.533/) | 将多维质量分数按权重聚合；用不同质量权重筛选数据，训练小型代理模型，再用 LightGBM 预测验证 Loss 来选权重。论文分析了指标相关性，提醒自然语言统计指标与 DSIR 指标可能高度冗余。方法见正文 §3 与 §4。 | A1–A3 有质量信号，但附件没有“不同质量权重筛选语料后训练代理模型”的实验结果。可借鉴分组与去冗余，不能将论文的学习权重直接当作本题数据学习所得。 |
| [QuRating, ICML 2024](https://proceedings.mlr.press/v235/wettig24a.html) | 从文本两两比较得到写作、所需知识、事实与教育价值四维评分；按评分的 softmax 权重抽样，温度控制质量与多样性的取舍。方法见正文 §3–§4。 | A1–A3 已含四维 `qurater` 信号，可用于质量评价；附件没有原论文的配对判别数据或真实预训练结果，不能声称复现其抽样增益。其“高分不等于唯一目标，多样性也重要”适合检验高质量集中是否造成域分布失衡。 |
| [RegMix, ICLR 2025](https://proceedings.iclr.cc/paper_files/paper/2025/hash/5f67d864aae6115374fed7beddd119e0-Abstract-Conference.html) | 在大量小模型的不同配比实验上，以配比预测目标域 Loss；论文比较 ridge 与 LightGBM，再搜索候选配比。关键跨尺度假设是配比排序相对稳定。方法见正文 §3。 | A4–A11 正是与其设计高度对应的数据。论文示例主要优化 Pile-CC 目标；本题要求 13 个验证域，须自行定义逐域或综合目标。A12–A15 是估算外推，不能当大模型实测。原题引用把其误写成“Xia 等，ICML 2024”。 |
| [Data Mixing Laws, ICLR 2025](https://proceedings.iclr.cc/paper_files/paper/2025/hash/cc84bfabe6389d8883fc2071c848f62a-Abstract-Conference.html) | 在固定训练条件下，用可解释的指数型函数描述配比与域 Loss；再与步数、规模的标度律嵌套。论文从两域、三域实验建立形式，再讨论多域。方法见正文 §3。 | 可作为 RegMix 的参数化对照；但直接在 17 域、512 条训练配比上自由拟合全参数指数式可能不稳定，须约束参数并用 A6/A7 检验。跨规模预测不能借论文结论代替本题实测。 |
| [DoReMi, NeurIPS 2023](https://papers.neurips.cc/paper_files/paper/2023/hash/dcba6be91359358c2355cd920da3fcbd-Abstract-Conference.html) | 训练参考模型与代理模型，通过各域的超额 token Loss 做 Group DRO，并平均训练中的领域权重。方法见正文 §2。 | 它需要逐 token Loss 与额外模型训练。A4–A15 只有配比与汇总验证 Loss，因此当前附件无法直接重现 DoReMi；适合作为机制比较，不作为本题可执行的主模型。 |

## 2. 每阶段的候选模型路线

### 阶段 A：22 信号合成质量分

| 路线 | 核心做法 | 优点 | 风险与所需证据 |
|---|---|---|---|
| A1 分组稳健聚合 | 按[原数据集字段说明](https://huggingface.co/datasets/opendatalab/SlimPajama-Meta-rater/blob/main/README.md)压缩 8 个列表字段、统一方向，再按教育价值、可读性、洁净度、结构四组聚合。 | 不需额外训练，全部 A1–A3 可复现；指标贡献易解释。 | 等权并非最优；用 A1 原文独立盲评与敏感性检验。当前分析报告的具体规则属于此候选路线，不预定最终采用。 |
| A2 潜变量/因子模型 | 在方向统一后，把强相关信号压成少量潜因子，再以因子得分构造质量分。 | 可显式处理 Meta-rater 指出的冗余；减少 22 维共线。 | 因子方向、跨 7 域测量等值性需验证；不能只按解释方差就称其“质量”。须用原文盲评对因子作语义校验。 |
| A3 监督权重学习 | 让 A1 原文独立人工标注形成质量目标，在校准集拟合非负权重或有序回归，另一评价集验收。 | 更贴近人工质量概念；可检验各指标增量价值。 | 人工样本少易过拟合，且人工质量与“预训练收益”不完全等价；不能冒称 Meta-rater 的代理模型 Loss 优化。 |

**比较规则**：三路线使用同一 A1 按域分层的校准/评价划分，同一 A2/A3 全量外部迁移检查；报告原文盲评的秩相关、域内稳定性、缺失拒评率和跨域分布漂移。质量分是多目标压缩，必须同时报告维度分数。

### 阶段 B：质量冲突识别与消解

| 路线 | 核心做法 | 适合检验的问题 |
|---|---|---|
| B1 规则与可靠度 | 先在语义可比指标对上检测高低矛盾，再按解析异常、短文本、域特征和真实权衡分类；对异常指标降权或拒评。 | 可解释、容易做原文案例核验；对 A2/A3 可复用相同规则。 |
| B2 稳健多准则聚合 | 用截尾均值、Huber 聚合或加权中位数减少离群指标影响，同时对严重广告/噪声施加非补偿上限。 | 检验“一个异常指标是否不应推翻其余指标”与“严重污染是否不能被高教育分抵消”。 |
| B3 排序/偏好模型 | 对 A1 人工标注文本对，用 Bradley–Terry 或有序比较学习整体偏好；把与信号聚合不一致的文本当成冲突案例。 | 更贴近 QuRating 的配对判断；需额外人工配对标注，暂不能用于 A2/A3 原文直接核验。 |

**比较规则**：预先分离人工校准集和评价集；用评价集的错判率、极端污染漏检率、域间冲突率稳定性比较，尤其检查 GitHub/ArXiv 的专业文本是否被语言统计量误罚。

### 阶段 C：17 域配比 → 13 域 Loss（核心）

| 路线 | 结构 | 优点 | 风险 |
|---|---|---|---|
| C1 可识别的稀疏响应面 | 用 16 个独立配比坐标，线性项加受约束的二次交互；ridge/层级稀疏估计。 | 能解释域间替代和组合效应，可在单纯形上优化。 | 512 个训练配比对大量交互可能不足；仅报告可行方向变化及区间，不孤立解释某系数。 |
| C2 RegMix 式预测器 | 对每个目标域分别拟合 ridge 与 LightGBM，再按预设目标权重综合；在训练配比覆盖区内搜索。 | 与附件来源对应，可捕捉非线性；预测能力有直接检验集。 | 树模型的边界优化和解释性弱；不能用 A6/A7 挑最优模型后仍称其独立检验。 |
| C3 受约束的数据混合法则 | 用正参数、单调性和共享/分层参数约束指数型配比—Loss 曲线。 | 与 Data Mixing Laws 的机理形式接近，便于向问题二的标度律对接。 | 17 域高维函数可能不可识别；仅在训练交叉验证与 A6/A7 同规模测试均有优势时考虑。 |

**公平比较**：先固定 13 域逐域 Loss 与一个等权综合 Loss；所有超参数和模型形式只用 A4/A5 的交叉验证确定。A6/A7 只做 1M 同规模独立测试，指标含 MAE、RMSE、Spearman、top-k 配方找回率。A8–A11 评估跨规模**排序和相对改善**，并检验 RegMix 的秩不变假设；A12–A15 仅讨论外推估算的方向一致性。若使用检验集反馈再修模，须标为探索性并另找新数据复验。

## 3. 阶段推进与当前决策

1. 本文完成的是**论文方法和模型可行性筛选**。A/B/C 各保留多条路线，核心配比阶段至少比较 C1、C2、C3；DoReMi 只作为理论参照。
2. A1–A3 的全量结构扫描已完成：51,230、17,523、203,752 条，A1 的 arxiv 1,419 条与 A2、github 10,000 条与 A3 按 `id` 重合；8 个多维字段在实际 JSON 中已是数值列表，非字符串。个别 ModernBERT 列表含非有限值，需作为该字段缺失处理。下一阶段比较质量评分路线，并在冻结评分基线后做 A1 原文评价。当前不填写质量排名或模型性能。
3. A、B 阶段的质量输出与 C 阶段配比实验不是同一批数据。若之后将质量分强行映射到 17 域，必须标明 A16 的 direct/near_direct/inferred 层级，并对缺失的 11 域给不确定区间，不能视为直接观测。

## 4. 来源与局限

上表均取自论文正式出版页面及正文方法部分；这不是系统性文献综述，也没有穷尽全部数据配比方法。各论文的训练资源、评测集、数据源与本题附件不同；其论文实验结果不能直接填作本题计算结果。Meta-rater 与 DoReMi 依赖额外代理模型训练，而题目不要求实际训练大模型。数值比较须等 A1–A15 真正处理和运行后给出。
