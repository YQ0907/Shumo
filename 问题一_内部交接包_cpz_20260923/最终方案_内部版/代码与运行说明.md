# 代码库与重现路径

`code/` 收纳了问题一两套实验的 **9 份原样代码快照**。`bundle_manifest.json` 逐一记录原位置、包内位置、文件大小和 SHA-256，供代码审阅和差异核验。快照的路径假设仍按原项目结构编写；通过 [`run_snapshot.py`](run_snapshot.py) 运行时会保留原脚本的路径语义，因此需要本项目原始附件目录仍在。该入口执行的是快照字节，`verify_bundle.py` 则要求快照与原件一致；如果未来改代码，应重新生成包并复核论文数字。

## 阶段与依赖

| 阶段 | 快照 | 读取 | 写出 / 作用 |
|---|---|---|---|
| 质量评分 | `quality_compare.py` | A1–A3 压缩原文与 22 信号 | `quality_results/sample_scores.csv`、域汇总与诊断 |
| 质量复算 | `问题一_质量与冲突实验.py` | A1–A3 | `问题一质量实验/` 的逐条评分与语义冲突 |
| 盲评核验 | `assess_ai_blind.py` | 两名 AI 子代理已填盲评表、质量分 | 135 条 AI 片段评分与相关摘要；不是人类评估 |
| 冲突策略 | `conflict_compare.py` | A1–A3 | `conflict_results/` 四对口径及策略比较 |
| 配比比较 | `mixture_compare.py` | A4–A15 | `mixture_results/` 多模型 CV/检验结果 |
| 局部情景 | `mixture_effects.py` | 配比比较输出 | 1 个百分点替换与双域交互情景 |
| 两任务质量对账 | `cross_session_audit.py` | 两套质量输出 | `cross_session_results/quality_conflict_reconciliation.json` |
| 核模型同口径比较 | `cross_session_mixture.py` | A4–A15、配比模块 | `cross_session_results/harmonized_kernel_results.json` |
| 外来方案对比 | `对比实验_问题一.py` | 另一任务的方案与数据 | 独立候选方案诊断；非当前主模型 |

## 环境与命令

本机重现实验的库版本在 [`requirements.txt`](requirements.txt)。在项目根目录运行：

```powershell
python '问题一研究\最终方案_内部版\run_snapshot.py' --list
python '问题一研究\最终方案_内部版\run_snapshot.py' quality --limit 200 --output '问题一研究\最终方案_内部版\smoke_quality'
python '问题一研究\最终方案_内部版\run_snapshot.py' mixture --output '问题一研究\最终方案_内部版\smoke_mixture'
python '问题一研究\最终方案_内部版\build_database.py'
python '问题一研究\最终方案_内部版\verify_bundle.py'
```

`quality --limit 200` 仍会读取全部 A1（约 51,230 条）作为校准参考，只把 A2、A3 限为各 200 条；该命令是运行检查，不是仅处理 600 条的完全小样本实验。

全量重算顺序：`quality` → `quality_alt` → `blind_audit`/`conflict` → `mixture` → `effects` → `cross_quality`/`cross_mixture` → `build_database.py` → `organize_bundle.py` → `verify_bundle.py`。无 `--output` 的旧脚本会覆盖其原实验结果目录；正式重算前应保留当前交接包，且重新审查论文表格。`quality_alt`、`conflict`、`blind_audit`、`effects`、两项 `cross_*` 均为全量过程，耗时和内存高于小样本检查。

## 本包与外部数据的界线

包内 `data/q1_evidence.sqlite` 已包含论文所需的逐条质量分、复算冲突、配比与 Loss、模型标量指标和局部情景。`evidence/` 保存小型原始结果快照，便于直接查看。A1–A3 压缩全文、A4–A15 原始 CSV、约 43 MB 的原质量评分 CSV 和约 30 MB 的冲突逐条策略 CSV 留在原位；库内 `source_file` 与包清单提供追溯入口。六篇原题 PDF 已复制进 `literature/`，附有下载说明和问题一用途笔记。
